# Aadi Shah | Portfolio

A portfolio of Aadi Shah’s software projects, experience, and contact details.

Live site: [aadishah17.github.io/Aadi-Portfolio](https://aadishah17.github.io/Aadi-Portfolio/)

## Features

- Project notes with links to source code and live demos
- Resume download and contact form
- Responsive layout built with React, Vite, and Tailwind CSS
- GitHub Pages deployment on pushes to `main`

## Run locally

```bash
git clone https://github.com/Aadishah17/Aadi-Portfolio.git
cd Aadi-Portfolio
npm ci
npm run dev
```

To use the contact form locally, copy `.env.example` to `.env` and fill in the EmailJS values.
